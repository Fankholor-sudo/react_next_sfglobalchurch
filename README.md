
# Spirit Fountain Global Church

## About the Project

Spirit Fountain Global Church is a modern, responsive church website designed to share the church's mission, connect with the community, and make church information easily accessible to visitors and members.

The website features a clean, elegant design with dark backgrounds and gold accents, reflecting the church's identity and creating a welcoming online experience.

## Features

* **Home Page:** Introduces the church and welcomes visitors.
* **About Page:** Provides information about the church and its mission.
* **Events Page:** Showcases church events and activities.
* **Sermons Page:** Displays sermon videos from YouTube, including the latest 10 videos.
* **Responsive Design:** Supports different screen sizes, including mobile phones, tablets, and desktops.
* **Modern UI:** Uses Material UI components for a consistent and polished interface.

## Technologies Used

* Next.js 16
* React
* TypeScript
* Material UI (MUI)
* YouTube video integration
* Vercel for deployment
* Next.js Image component for image handling

## Getting Started

### Prerequisites

Ensure you have the following installed:

* Node.js
* npm

### Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/Fankholor-sudo/react_next_sfglobalchurch.git
   ```

2. Navigate to the project directory:

   ```bash
   cd react_next_sfglobalchurch
   ```

3. Install dependencies:

   ```bash
   yarn install
   ```

4. Start the development server:

   ```bash
   yarn dev
   ```

5. Open your browser and visit:

   ```text
   http://localhost:3000
   ```

## Deployment

The website is deployed using Vercel. To deploy your own version, connect the repository to Vercel and follow the deployment instructions.

## Project Purpose

The purpose of this project is to establish a strong online presence for Spirit Fountain Global Church, improve access to church information, share sermons, and keep the community informed about church events and activities.
